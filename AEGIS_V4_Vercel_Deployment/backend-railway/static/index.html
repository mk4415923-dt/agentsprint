How do I get Gmail OAuth credentials?
  1. Open Google Cloud Console and create/select a project.
  2. Enable Gmail API, set the OAuth consent screen and add your account as a test user.
  3. Create an OAuth client of type Web application.
  4. Add redirect URI http://127.0.0.1:8765/api/gmail/callback.
  5. Paste Client ID and secret below. Connect and grant Gmail access.

Gmail integration here requires its own Google Cloud OAuth client. ChatGPT's Gmail connection does not automatically authorize this local app.

OPERATOR HANDBOOK

How AEGIS works.

Plain-language steps for non-technical university staff and judges.

01 · PREPAREConnect Gemini

Settings → paste your Gemini API key. No AI inference runs until you configure it.

02 · ANALYZERun AI agent

Overview → Run AI agent. It reads each local JSON email, plans, retrieves relevant policies, evaluates risks and writes a reply draft.

03 · REVIEWCheck before anything leaves

Inbox → open a student email. See original message, evidence codes and editable reply. Save and approve explicitly.

04 · OPTIONAL GMAILConnect test Gmail

Settings → authorize Gmail for reading and sending, then enable Live Email Delivery. Every outgoing reply still requires human approval.

05 · POLICYChange the rules

Policy Library → Update policy. Each publication is saved as a new version and old drafts must be re-analyzed.

06 · PROVE ITReview audit trail

Activity & Reasoning stores tool summaries, exception details, approvals, edits and Gmail provider receipt IDs. These are public operational decisions, not hidden chain of thought.

What each status means

Statuses are based on real Gmail provider events. A provider receipt does NOT prove inbox delivery.

${'Awaiting AI'}

Draft ready

AI wrote a draft. Staff should check the recommendation.

Needs human review

Emergency, uncertainty, escalation, or a manual change that requires approval.

Approved · not sent

A staff member approved the exact draft. Approval does not deliver mail.

Google accepted · delivery unverified

The Gmail API returned a message ID, but recipient inbox delivery is not proven.

Delivery uncertain

Never automatically retry after a timeout. Check Gmail Sent folder first.

How to fix common errors

Gemini 429 / quota

Too many requests or no API quota. Wait for reset or use a permitted key/model, then retry.

Gemini 401 / 403

Check API key, model access and account permissions under Settings.

Gmail OAuth redirect mismatch

The Google Cloud OAuth Web application must allow http://127.0.0.1:8765/api/gmail/callback.

Sent button not shown

Requires an approved draft, connected Gmail with send permission, enabled Live Email Delivery and administrator confirmation.

Old policy blocks approval

Run this case through the agent again using the latest policy, review and approve.
